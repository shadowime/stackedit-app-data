## 冒险模组

前面几章的所有内容——机制与规则、世界观的描绘、给玩家和说书人的建议——最终都会在牌桌上通过一场场冒险成形！

如果你只是偶尔和朋友凑一个晚上，用一场冒险来讲个故事，那额外准备一大堆冒险模组可能会有点接不上茬。但这种玩法的好处是：你只需要一个能坐下来玩的地方，加上一个简单的冒险点子就够了。要是你打算长期固定开局、用同一批玩家和同一群小猫把冒险串成一场战役，那就需要再多一点点结构上的安排了。

本章要聊的正是这件事，里面收录了好几个冒险示例，写法格式略有不同；还附了一些带场技巧，以及如何在前几章所有信息的灵感基础上，自己再写新冒险。

### 开一场战役

一场战役，就是同一批玩家、同一群小猫，连着开好几个晚上打下来的一整条冒险线。它通常有一条贯穿始终的主线，由一个个或多或少独立的小故事串联而成。

在《地城小猫》里，一场战役的主线就是小猫们和沃尔特的关系：它们会不会想给他带回些财宝？会不会想找帮手、一起推翻他的统治？还是干脆离家远走、过自己的小日子？一条主线能把各个小故事串起来，给它们一个大方向；不过小猫们也完全可以只是逛逛这个世界、认识认识当地居民，对那里发生的各种故事产生兴趣。

说书人大可放开手脚，把前几页里的所有材料都拿来搭自己的冒险——也尽管自己编故事。下面你会读到四个不同的冒险。

> **跑一场战役**
> 战役就是同一批玩家、同一群小猫，连着若干个晚上打下来的一整串冒险。为什么是它们被放逐到他身边、远离家人？一条战役主线的作用，就是把各个小故事彼此连起来，给它们一个大方向；但小猫们也大可以只是游历世界、结识住民，对那里发生的故事产生兴趣。

第一个冒险《斯克兰布尔奶奶失踪案》（第 207–215 页）可以当作小猫们的入门——这是它们被逐离猫树城、在外流亡的第一晚——也是一个结交新朋友、直面坏蛋的好机会。用它来开启小猫们的旅途再合适不过。

第二个冒险《三只小猪》（第 217–230 页），适合在跑过几个零零碎碎的小插曲之后再开（这些小插曲由说书人自己去编），那时小猫们也终于来到了软木镇。这是战役里的一个关键节点：如果一切顺利，冒险结束时小猫们会找到一位恩主、一个得力的盟友，还有一个大本营。要是它们决心正面硬刚沃尔特、把这个暴君赶跑，这些资源就格外派得上用场！

第三个冒险《塞勒涅的噩梦》（第 233–244 页），是一种可以反复触发的事件：小猫们要么自己撞上、要么根据情境偶然闯进去。这是一场梦境般的冒险——小猫们会被卷进森林之灵的梦境之中，必须竭尽全力让它重归平静。很可能得来回跑好几趟，才能把那些坏念头永远赶跑——或者顺便捞回点财宝。

最后一个冒险，用它发生的那座大地城来命名：《绯红领地》（第 247–260 页）。那是个古怪又危险的地方，小猫们或许能在那儿找到它们种种疑问的答案，多了解一点这个世界的秘密。每当它们拿不定主意该怎么办、或者被困住不知如何脱身时，都可以前往绯红领地——比如借助 大浣熊互联网 的秘密地道（见第 121 页）。在那里探一探，它们很可能找到所需的全部答案……前提是活得下来！

### 斯克兰布尔奶奶失踪案

#### 流亡路上

和此前许许多多的小猫一样，咱们这场冒险的英雄们也是被沃尔特大王放逐的。它们满心悲伤地告别了家人、朋友和家园。幸运的是，小猫之间代代相传着一个秘密：流亡的第一晚，只要走上古森林道，就可以顺道去斯克兰布尔奶奶家落脚，讨个歇处、求个指点。

小猫们沿着古道深入森林，在一处几乎看不见的小岔路口，发现了一座滑稽的母鸡木雕——它展开翅膀，指向一条小径。

斯克兰布尔奶奶是只老猫，住在森林里的一间大屋子里，周围围着几百只鸡。那些鸡舍一座比一座华丽，全是用捡来的五花八门材料搭起来的。每周一次，奶奶会去猫树城桥头卖她的鸡蛋（见第 93 页）。可今晚，鸡群心慌慌的：没人来添饲料、没人来添水。屋子本身朴素得很，可今晚门大开着，灶火也没生。里头一团糟，东西撒得到处都是。斯克兰布尔奶奶不见了。

#### 场景一

有外人闯进来袭击了斯克兰布尔奶奶。屋里有打斗痕迹：东西被撞翻、扒拉到一边，还有一撮撮被扯下来的毛！肯定是打过一场**亮爪战**！

一队人马的脚印——四个负重不轻的家伙——一路延伸进森林——而且不只有猫的脚印：其中一个块头极大，另一个很可能是只母猫。

屋里少了一把椅子，地板上还有麻绳纤维的痕迹——斯克兰布尔奶奶是被绑走的！

一个袭击者把一把钳子落在了家具底下。金属上刻着个小记号：一弯月亮，下面像挂着个小盒子——这是穆纳先生的标志。穆纳先生，一个臭名昭著的走私犯，正被沃尔特通缉。

> **线索怎么查**：以上线索，只要一次成功的**聪明**检定就能找到——或者问几个恰到好处的问题也行。

**事情的真相是**：斯克兰布尔奶奶晕过去了。她上了年纪，身子早不如从前硬朗。几只胆大的鸡自告奋勇跑进森林，去请奶奶的一位老朋友——穆纳先生——来帮忙。他尽快赶了过来，带着老猫一起走了；可因为又急又慌，他手下的人把屋子弄了个乱七八糟。

#### 场景二

通常小猫们会顺着脚印追下去；不过，要是它们决定在茅屋里过夜，下一场遭遇也大可以就在这儿发生。

它们一走进森林，就有个声音招呼道：“哟呵，小猫咪们，这么晚了还出来遛弯呀？要不要搭把手？乐意的话我给你们带路，这一带我熟得就像熟悉自己的爪垫背。”

搭话的是一只形迹可疑的黄鼠狼，牙黄黄的，右眼是只瞎眼、中间划着一道疤，肩上搭着件破斗篷，腰里别着把大砍刀似的家伙。他身边跟着个沉默的大块头**猫坚果**猫坚果，蠢得跟他的力气一样大，棕黄的毛上挂满树叶和荆棘刺，肩上还扛着一口大黑锅。鸦趾；油滑。

他俩叫鸦趾和油滑。要是斯克兰布尔奶奶在家迎接小猫们，准会提醒它们提防这俩！

黄鼠狼鸦趾是沃尔特雇的临时爪牙，专门在树林里盯着，一旦有小猫回到王国附近晃悠就去报信。鸦趾恨穆纳先生——因为穆纳每次都把他吃得死死的。

只不过今晚，穆纳先生留下了一条再明显不过的踪迹。

理想情况下，小猫和这两个坏蛋之间该打一场**呲牙战**——这俩想把小猫领到一个地方，好让同伙把它们逮住、押到海边去船上干活。

小猫们当然会赢，把坏蛋们打得落荒而逃。他俩会回去报信给沃尔特，沃尔特就会派卫兵去追剿穆纳先生。要是小猫们输了，它们就得逃进森林躲追捕——结果一头撞进穆纳先生的营地。

#### 场景三

小猫们顺着脚印，一路找到穆纳先生和他那伙走私犯藏身的小山谷——就在一汪漂亮池塘的边上。

通常那地方极难靠近。多年来，穆纳先生种满了各种灌木：山楂、冬青、卫矛、小檗、蝎尾豆、荆棘、桑树篱、剑草，等等。有一条小径能穿过这一切天然障碍，但极难找着。唯独今晚，穆纳先生一心急着救奶奶，一路猛冲过来，没像往常那样做遮掩。

穆纳先生的藏身处，是几个并排拼在一起的旧运输集装箱，藏在树木和灌木丛后头。其中一个透出一点微光，小猫们可以悄悄靠近、不被任何人发现。

> **说书人注**：穆纳先生夜里靠池塘里的巨型蜻蜓，把货物运过城墙。

斯克兰布尔奶奶躺在一张雕工精美的木床上，身边围着好几个家伙：

**穆纳先生** // 优雅的姜黄色公猫，琥珀色大眼睛，打扮得像个花花公子，手里拄根手杖 // 强壮 3 / 聪明 5 / 可爱 4 // 心点 8 // 搜集情报；嘶吼威吓；镇定自若；人文地理；魅惑迷人 // 一根精致手杖；漂亮衣服；一把钳子（丢了）；一块能听懂节肢动物语言的魔法石。

**露西夫人** // 年轻的虎斑母猫，穿皮甲，背上扛把大剑，脖子上围着条色彩鲜亮的围巾 // 强壮 4 / 聪明 3 / 可爱 4 // 心点 7 // 悄行；挥爪；扭臀摆尾 // 皮甲；大剑。

**格雷娜达** // 苗条结实的狐狸，眼睛滴溜溜乱转，曾被年轻时的穆纳先生从沃尔特的地牢里救出来 // 强壮 4 / 聪明 4 / 可爱 3 // 心点 8 // 辨向寻路；观察搜寻；扭臀摆尾 // 一把万能钥匙；结实的绳索。

**嘉莲娜** // 巨大的森林蜘蛛，极老、极聪明，能心灵感应 // 强壮 2 / 聪明 5 / 可爱 3 // 心点 7 // 疗伤治病；狩猎采集；草药学 // 一顶小帽、一条项圈。

这场遭遇可以有好几种走法。原来穆纳先生正是斯克兰布尔奶奶收留的第一批小猫之一——就在他流亡的第一晚——是她多年的至交好友。他把大批货物偷运进城、一分税也不给沃尔特交。

嘉莲娜会给斯克兰布尔奶奶治伤——她病得不算重，只是鸡蛋吃太多，身子变得有点虚。以后得忌口：多喝汤，炒蛋少吃。

#### 场景四

突然，一声猎号吹响，喊声四起。

被鸦趾告了密的城卫兵，顺着穆纳先生的踪迹追来了。这最后一场戏，让年轻小猫们有机会跟皇家卫兵（领头的是一脸凶相的西克利中士西克利）玩一把躲猫猫，从走私犯的窝点脱身、再把他们甩进森林。

**西克利** // 猫树城城墙上讨人嫌的卫兵中士 // 强壮 4 / 聪明 2 / 可爱 2 // 心点 6 // 搜集情报；嘶吼威吓；扭臀摆尾 // 皇家卫队罩袍；一根又大又沉的棍棒；烟斗和烟丝。

**皇家卫兵** // 普通卫兵，不太勇敢，也不太上心 // 强壮 3 / 聪明 3 / 可爱 3 // 心点 6 // 嘶吼威吓；扭臀摆尾；观察搜寻 // 皇家卫队罩袍；又大又沉的棍棒；一把报警用的号角。

每只小猫都可以想出自己的计划，然后描述出来、说说打算怎么干。接着玩家们掷骰看能不能成。

要成功甩掉卫兵，玩家们总共需要掷出的成功数，等于小猫数量的 4 倍，而且最多只有两轮桌时。要是两轮过后成功数还不够，穆纳先生的窝点就暴露了！

设下埋伏、在一场**呲牙战**里把西克利揍趴下，直接算 4 个成功（不管那场战斗实际掷出了多少成功）！

也很容易说动一部分卫兵往别处看——尤其要是搭话的那只小猫出身军人世家。

#### 结局

斯克兰布尔奶奶一养好，就会把小猫们带回家，给它们做顿好吃的，再掏心窝子地叮嘱一番。以后它们若要进出猫树城，也尽管找穆纳先生和他那伙人帮忙；他还总能替它们捎信给爸妈，或者交上几桩“走私”小活儿给它们练练手。

### 三只小猪

#### 软木镇上的城市任务

小猫们来到软木镇（见第 143–152 页），遇见了罗西·罗斯维尔夫人罗西·罗斯维尔，一只母猪，正急着找人帮忙找她的三个儿子。三个儿子进城闯事业，可她从此再没收到半点音讯。事情一环扣一环，小猫们的调查渐渐牵出一桩险恶阴谋——它不光危及三只小猪，连软木镇男爵也难逃一劫。

- **引子——一位无助的母亲**：小猫们正扮演英雄时，遇见了罗斯维尔夫人。她大为感动，央求它们找回自己的三个儿子。
- **第一章——稻草、木棍和砖头**：小猫们走遍全城，在调查中遇见形形色色、五颜六色的人物。它们渐渐发现，三只乡下小猪惹上了大麻烦。
- **第二章——沃尔夫里克的肚子里**：小猫们揭穿了沃尔夫里克的计划。这是个铁了心要害男爵的匪类，三只小猪已落入他的魔爪。小猫们只需救出它们、终结沃尔夫里克的贿赂阴谋即可。不过千万当心——这是一场和时间的赛跑：必须趁一切还来得及，先粉碎沃尔夫里克的计划！
- **尾声——一家人的事**：小猫们亲眼见证三只小猪和妈妈团圆。新的机遇随之打开。

#### 争吵

这个剧本围绕着两群配角展开，说书人务必把它们各自的角色弄清楚。这些配角的资料见第 229–230 页。

**斯诺特、斯诺弗和斯诺菲**，是罗西·罗斯维尔夫人的三个年轻儿子。他们的爸爸丘巴马林在他们还小的时候就失踪了，于是他们跟着妈妈，住在一个简陋的小村子里。三兄弟满脑子主意、蹄子也灵巧，他们凑齐所有积蓄来到软木镇，想合伙开一家自己的建筑行。问题是：他们永远谈不拢——不管是怎么盖房子，还是该用什么最好的材料。

斯诺特爱稻草。它轻、好运输、便宜、隔热一流，还可再生。斯诺弗是回收材料的粉丝：旧漂木、木棍、硬纸板、纸，不花一分钱，想怎么摆弄就怎么摆弄。斯诺菲只认石头——结实、耐久，正适合这座漂亮的摩登城市和它阔绰的居民。没有了妈妈在身边镇着，又接不到工程合同，三兄弟吵了个天翻地覆，甚至动起手来，最后一拍两散，从此互相气呼呼的。

沃尔夫里克，白天是个普通码头工。到了晚上，他摇身一变，成了钩子区（见第 230 页）令人闻风丧胆的帮派头目。沃尔夫里克的真名其实叫“里奇”。他是只块头极大、孔武有力的公猪，对男爵嫉妒得要命。事实上，沃尔夫里克是男爵的表亲——一个几乎没人知道其存在的表亲。他是前城市男爵莱拉布的私生子，也就是现任统治者恩伯呼噜·林斯威思-古特罗特恩伯呼噜·林斯威思-古特罗特的堂兄弟。要是他爹生前认下他，这男爵本该是他来当。沃尔夫里克靠胡作非为和偷摸扒抢攒下了一小笔家业。他唯一的心愿，就是推翻恩伯呼噜，自己当上软木镇的新男爵！

而沃尔夫里克的好日子眼看就要来了。为了巩固对城市和他那不安分家族的掌控，恩伯呼噜男爵下令在保护港口的那条大栈桥的尽头，立起一座自己的雕像——好让进城的访客第一眼、离城的最后一眼都看见他。沃尔夫里克打算把原来的石头底座换成一匹特洛伊木马：一个空心底座，他和手下可以藏在里头，等雕像落成典礼上纵身扑向男爵。他看见三兄弟为盖房技术吵作一团后，就把他们绑了来，逼他们给自己造假底座，从此把他们关在一间仓库里。

> **落成典礼的日子近在眼前**：小猫们没多少时间去找回三只小猪、阻止沃尔夫里克的阴谋了！

#### 引子

傍晚时分，小猫们正走在盐门（见第 145 页）附近，忽然被一声呼救吸引了过去。

一只雪白小兔子，在街头卖货，正被四个来自“红钩帮”的恶棍围攻。他们想抢她那篮缎带、漂亮蝴蝶结和手帕。兔子名叫雪球，趁小猫们出现，赶紧躲到它们身后。

接下来是一场干脆利落的**呲牙战**：这伙坏蛋想在街坊面前耍耍威风，可一见形势不对，撒腿就跑。

不管输赢，小猫们面对强盗时的勇敢劲儿，引起了罗西·罗斯维尔夫人的注意（见第 229 页）。于是她邀请它们——还有雪球——去她下榻的粉海鸥酒馆（见第 143 页），要请它们喝一杯、吃块好蛋糕。

罗斯维尔夫人很快就向小猫们求助：她的三个孩子斯诺特、斯诺弗、斯诺菲几个月前进城来了，可她至今音讯全无，急得不行。她一路从乡下村子找过来，却完全不知从何下手。她甚至愿意用自己仅有的一点家底——她攒了一辈子的血汗钱——来酬谢勇敢的英雄们，酬劳它们花的时间和力气。

#### 第一章：石头、稻草和木棍

这场冒险的第一部分是调查：小猫们走访全城、采访居民，搜集关于三只小猪的情报。从罗斯维尔夫人给的零星线索出发，玩家们会顺着调查的线头，尽量多搜集关于事态、三兄弟、他们争吵的缘由、遭遇了什么、以及眼下身在何处的线索。用下面给出的线索清单，按大概的先后顺序喂给玩家，直到小猫们准备好进入第二章。

> **调查类剧本怎么跑**：在调查类剧本里，玩家靠向说书人提问来搜集情报。玩家每提一个问题，说书人都必须给出一个有意义、或有意思的回答。没有回答，玩家就会原地打转、不知如何是好、最后无聊透顶。玩家是通过自己的小猫行动的：到处跑、盘问配角和证人、读信的是它们；但动脑筋、绞尽脑汁想搞清楚来龙去脉、琢磨怎么用说书人的回答推进调查的，是玩家本人。

既然说书人事先无法预知玩家会问什么——又必须给出回答——就不该事先拍板“某条线索在某个时间、某个地点、某个配角身上”。那样恰恰会把玩家困在原地、永远找不到线索。你得灵活变通：要是小猫们去盘问客栈前那个老乞丐猪，他就该把重要情报吐出来；而不是那个谁也没去搭话的客栈老板（哪怕一开始你打算让老板开口）。要紧的是情报和线索最终送到玩家手里。说书人要抓住一切机会透露信息，让玩家拿它做点文章，再顺藤摸瓜去往下一条线索。

这也意味着说书人要避免假线索、假情报。她可以含糊其辞、可以让人摸不着头脑——只要她想让小猫们多费点劲——但绝不能说谎、不能存心欺骗。玩家就算没人帮，也完全会自己冲错方向！

整场冒险里，说书人都该不时铺陈一下背景：为恩伯呼噜男爵当权周年大典所做的种种筹备。铁腰团（见第 148 页）正逼着市民把街道扫干净，房屋之间拉起彩旗横幅，大建筑披红挂彩；而在这一切之上，栈桥尽头那尊巨大的男爵雕像正在赶工。城里成千上万家客栈，为了在大典那天招揽客人，都在拼点子、打擂台：竞赛一项接一项地宣布，临时甲板和露台也一座座搭起来。

罗斯维尔夫人眼下唯一的线索，是几周前收到的一封信——三个孩子在信里说，他们寄宿在弗兰奇夫人的供膳房里；还说自己正在钩子区材料市场，跟工头和工人们打交道。小猫们想按什么顺序查，都随它们。

弗兰奇夫人是个脾气坏、爱找茬的老鸭子。想让她开口可难了——除非是骂邻居、或者训斥那些在她家门口晃悠的孩子。据她说，三只小猪吵吵闹闹、争执不休，不过房租倒是从不拖欠。他们走得很突然，但那是他们自己要走的。只要态度得当——或者来一次成功的**可爱**检定——就能说服她让小猫们去看看三兄弟住过的阁楼。弗兰奇夫人还没来得及收拾那房间：三兄弟可不大整洁。床底下有廉价啤酒的空瓶子，是从“此地胜彼地”酒馆此地胜彼地（见第 146 页）买的。还有一大堆从钩子区市场开来的建材采购单、涂得乱七八糟的发票。

还可以盘问弗兰奇供膳房的其他住户：老眼昏花又耳背的兔子奶奶娜娜·胡萝卜娜娜·胡萝卜；两个淘气、爱刨根问底的小猫娃的妈妈近视太太；几乎从不在家的铁腰团图尔迪；最后是一对年轻松鼠夫妇咔嗒与啪啦。他俩是杂技演员，聊起大轮子时满脸羡慕。他们自信满满，还当场要在房间横梁上翻跟头露一手。他们之中有一位（也可能是别人）或许会想起见过个形迹可疑的家伙——可能是只狐狸——好像一直在盯着阁楼和那三只猪。

去钩子区的材料市场走一趟，小猫们就能多了解这工人区的经济脉搏。整座城市和它的舰船所用的一切建材，都在这儿买卖：伐木工、采石工、回收匠、农夫、佃户、自耕农、机修工、工人、老板，全在这儿碰头，闹哄哄、热腾腾，把这座城市的精气神展现得淋漓尽致。阁楼里翻到的采购单上有个名字：金钳蟹。不过只要小猫们在市场上问对了问题，照样能探出他的名字。

金钳蟹是个大忙人，没工夫搭理小猫。他的保镖把路守得死死的，根本近不了身。小猫们得放机灵点，绝不能粗鲁、不能动武，要想硬塞个由头、从他那儿蹭走几分钟宝贵时间，就得有个好借口。它们也可以去盘问金钳蟹的伙计们——比如亚丹，一头看起来凶巴巴、其实心肠不坏的大公猪。

它们最后会摸清：三只小猪在任何事上都谈不拢——一个下单订材料，另两个立刻把订单退掉。他们为了用什么技术、什么材料，吵个没完没了：木头还是稻草？石头还是砖头？人工造的、还是老祖宗留下的回收料？有一回，金钳蟹不得不叫保镖来把打作一团的三兄弟拉开。多半还会有人跟小猫们提起：当时有个让人心里发毛的家伙，好像一直在盯三只猪——一只独眼老公狐，大家都知道他常泡在“此地胜彼地”酒馆，那家店正对着代达罗斯区。

“此地胜彼地！”是个脏乱差的地方。全城渣滓都在这儿晃。要不是看场子的臭屁隆下手狠、眼神凶，打群架的能从早打到晚。无论是臭屁隆还是客人，起初都不肯搭理小猫的问话：前者没工夫，后者要么凶神恶煞、要么一声不吭，还瞪来瞪去、满眼威胁。不过最后臭屁隆会给小猫们开个条件：要是它们打烊后留下来，帮她把里里外外打扫干净、把东西归置好（这活儿让人想起海格力斯清扫奥吉亚斯牛棚！），她就把自己知道的关于三只小猪和那只狐狸的事，统统告诉它们。

三只小猪成天泡在廉价啤酒里，吵个没完——啤酒喝得越多，吵得越凶。他们身上总揣着一堆碎纸片和图纸，扯着嗓子争论工法和工地。要是小猫们还没去过，臭屁隆会指点它们去三兄弟住过的供膳房，以及他们常去的那个市场。

那个独眼老公狐叫巴纳比。最近他一直在紧盯、尾随三只小猪。巴纳比是个老混混，被铁腰团抓进去过不知多少回。今天当海盗、明天当强盗，但永远是个贼、永远满嘴瞎话。这几个月他声称自己替码头的新老大干活——一个叫沃尔夫里克的恶角。没错，有人见过他在仓库区晃悠。

#### 第二章：沃尔夫里克的肚子里

三只小猪失踪好几周了，哪儿都没人见过他们。小猫们唯一的线索，就是那个叫巴纳比的独眼老公狐（见第 230 页）。它们得下到港口去找他。

**快去救人！**

港口热闹非凡。看来今天下午就是新雕像的落成典礼。男爵一行要穿过整座城，一路走到栈桥尽头。水手和船长们正忙着擦洗船只、挂起几百面彩旗。码头扫得干干净净，板条箱和街道家具统统收走，免得挡道。

老仓库区格外忙碌——因为雕像和它的底座，正是在这儿赶制、组装好，才运上栈桥的。

小猫们要么在仓库区里瞎转悠（**聪明**检定），要么盘问当地人（**可爱**检定），最后总能发现那只狐狸。它们也可以自己想办法：找到他、接近他、逮住他——设个套子、用一笔好买卖引他上钩、利用他的关系，等等。别忘了时间不多了：一切都得在今天解决！

巴纳比一旦被逼到墙角，会撒腿就跑、或者负隅顽抗，但他没疯，敌人太强就会投降。他绝不会跟谁打一场**亮爪战**！这老混混一把年纪了，更想靠出卖情报换条活路。

他最后竹筒倒豆子：三只小猪被关在 13 号仓库里，日夜不停替沃尔夫里克雕雕像底座的复制品。这个匪首已经把真底座掉了包，打算藏进赝品里，在男爵周年大典上给他来个背后突袭。

13 号仓库由沃尔夫里克手下两个狠角色把守：浑身疤的大公猪文尼，和满身刺青的小龙虾鲁迪（两人见第 230 页）。小猫们得靠力气或诡计把他俩搞定。三只小猪兄弟被锁在三个铁笼子里，笼子从仓库天花板上吊下来。地板正中央，就是被沃尔夫里克掉了包的那个真底座。

要是小猫们想找铁腰团帮忙（见第 148 页），十有八九会被无视，要是纠缠不休，甚至会被威胁要抓起来——铁腰团忙着呢，要盯着市民、守卫典礼。

三只小猪一被救出（见第 229 页），就会向救命恩人道谢，把沃尔夫里克那个蠢计划讲给它们听（他们担心得不得了）。就在这时，外面响起一阵号角！

**喂——男爵大人！**

小猫们必须穿过警戒线，走到栈桥尽头。它们得机灵、得聪明。玩家多半会想出各种各样的计划。说书人挑出最有意思的障碍、最贴边的能力检定来应对，最重要的是——要让小猫们走到终点时，觉得自己刚刚闯过了最最难的关！

栈桥上挤满了人，旁边还泊着许多船。小猫们的挑战是：一路走到栈桥尽头（人堆里挤更难、但从一条船蹦到另一条船上更容易），同时尽量不引人注目（被观众围着反而好藏、站在船上就显眼了）。到处都是铁腰团，可他们忙得很，不可能把每条路都堵死。

三只小猪主动请缨：制造点混乱、吸引官方注意力，或者干脆闹出点事故来。

第二步：粉碎沃尔夫里克的计划。这恶棍和他的党羽就藏在空心底座里。时机一到，他就要从一道暗门里跳出来，一把抓住男爵、把他拿下——羞辱他一番之后——篡夺大权！

说书人得同时操控一大群人打这场群架：沃尔夫里克和他的党羽、男爵和他的铁腰团、小猫们和他们的盟友、围观群众，等等。别慌：一场大猫战，不过是一场接一场的小猫战。你只需盯住那些重要的——小猫们亲身卷入的猫战；其余的打斗，讲故事一样带过即可。一开始都只是**呲牙战**：目的是压倒对手、吓唬他们、逼他们跪、逼他们服、逼他们逃。

只有事情彻底失控时，沃尔夫里克才会想跟他那位男爵表哥打一场**亮爪战**。小猫们可能得豁出命去救恩伯呼噜！

会冒出哪些选项，全看玩家出什么点子、它们的小猫做什么。下面这张单子不是定死的：小猫们堵死暗门、不让坏蛋从底座里冲出来；说动几个铁腰团来帮忙；护住男爵——男爵本来还想跟沃尔夫里克硬顶，直到一场亮爪战打响；把那批不领情的群众拉到自己这边，等等。

场面一定要宏大：局势反转再反转，群众一会儿倒向沃尔夫里克、一会儿倒向男爵；林斯威思-古特罗特家的宾客和成员各站一边、或者干脆想自己夺权。还有那座底座本就不牢靠、固定得稀松的雕像，随时可能一头栽进港口、把路堵死……

视情形而定，沃尔夫里克要么被逮、要么成功脱逃、甚至可能赢下这场对峙。他那伙党羽也还得一个个收拾。这一切全看对峙中爆发的暴力程度。

#### 尾声

假设小猫们保住了男爵的小命，第二天，恩伯呼噜男爵就在宫殿里接见它们，向它道谢、给它奖赏。他端详了小猫们一会儿，然后抛出一个古怪的提议：他需要一些独立的秘密特工——要有胆量、有勇气、有主见。他向它们吐露自己对这座城市的盘算，说自己不得不装出一副暴君模样，以防家族里有人来抢权（就像沃尔夫里克干的那样）。只要小猫们肯为他效力，他手头有的是任务。

回到粉海鸥酒馆，罗斯维尔夫人跟三只小猪团圆，高兴得不得了，可还是一遍又一遍地训他们：骂他们吵架、酗酒、不学好。她叹道：“你们为啥就不能把所有材料一块儿用上、好好合作呢？”——那座假底座他们不就是没吵架、一块儿做出来的嘛。

三兄弟向小猫们保证：哪天要是它们在软木镇相中一块地，他们一定免费给它们盖一栋房子，报答救命之恩！

### 塞勒涅的噩梦

小猫们被困在塞勒涅的噩梦里。它们必须尽快脱身，或者安抚森林之灵，好让太阳重新平静地升起。

这个冒险以一连串随机表的形式呈现——你会掷很多次骰，来生成构成故事的每一场遭遇。说书人要先确定遭遇发生在哪儿：在第 234–236 页的“地点”表上掷两次结果。第一次结果决定小猫们从哪个入口钻进来；第二次结果决定从那个地点通往何处的出口。

要生成每个地点结果，你可能需要多次掷 1d6，按该结果各列所示，确定地点类型和它的具体形态。

对地点表上的每个结果，先读该结果的描述，再按指示去“氛围”表（第 238–239 页）或“事件”表（第 241–244 页），生成遭遇的相应部分。当然，说书人也可以不靠骰子、自己来挑；她甚至可以随心所欲地编元素，视小猫们的所作所为、玩家们冒出的点子而定。

玩家们可以试着画张地图，用线条和圆圈把各个遭遇点连起来，标出自己在森林之灵躁动梦境里走过的路线。

梦里的每场遭遇都跟下一场不同。一场遭遇结束后，小猫们可以选择留在梦里，或者抽身离开、结束这场冒险——没准还顺手挣了点财宝。有时它们得跟梦里的怪物打上一架、打赢它们；有时则要解救被困的动物。但每一次胜利，都是让塞勒涅好起来的又一步。

### 绯红领地

在这个国家的极北之地，一段狂野陡峭的海岸线尽头，藏在一处看不见公海视线的隐秘小湾里，坐落着最古怪、最危险、也最有名的地方：绯红领地。它的名字是传奇，关于它的故事数也数不清。其中多半是彻头彻尾的谎话，或者更糟——是几个吹牛大王往谣言里添油加醋，可他们连那地方边都没挨过。

不过，有些故事是真的：绯红领地有喵法。绯红领地会夺命。绯红领地绝不留情。全世界的秘密都能在那儿找到：关于过去、现在和未来的知识。最简单或最刁钻问题的答案、最复杂难题的解法……统统都在。你要做的，不过是敢走进去，直面里头那一大堆陷阱和住民。

活着出来的人都会作证：绯红领地给了他们想要的东西，但他们从不愿多谈那儿到底发生了什么。再说了，谈也没用——因为没有哪两次造访绯红领地是一样的。

绯红领地是本作书名里那座最富盛名的地城，也是小猫们很可能为了打听消息、寻求帮助而反复造访的地方。它是个永远在变的场所。小猫们每次去，都跟上次截然不同。

> **说书人注**：绯红领地是被设想成一个困在时间异常里的地方。它永远不会重复，因为这地方是它所有“曾是”与“将是”的总和的倒影，却从不一次性全部呈现、从不完整。它既先进又野蛮，既被精心打理又一片废墟，既有住民又空无一人。它装着你需要的一切、你为了好玩能想象的一切，以及一切能让你还想再来玩的东西……

#### 抵达绯红领地

小猫们最初会听说这么一个神秘、极其危险的地方。旅人会聊起它——酒馆客栈里的客人、路过一晚的朋友，也许还有斯克兰布尔奶奶，或穆纳先生。当小猫们陷入困境时，说不定还是林斯威思-古特罗特男爵本人提起它。

渐渐地，小猫们可以靠提问、或遇上去过那儿的动物，一点点攒起关于这地方的线索和情报。

绯红领地在国土北方、靠近大海，是个难以抵达的地方。

那地方古里古怪。据说当太阳或月亮以特定方式排成一线时，有人看见它时隐时现、凭空消失又随机重现，或在某种光线下反应怪异。绯红领地似乎有几十个不同入口，去过那儿的人讲起路来也永远各不相同。至于它长什么样、在哪儿——去多少次都没用：每次都不一样。

那儿危险重重：怪兽、陷阱、谜题、死路，还有阴招，防不胜防。你完全可能一头栽进绯红领地深处、再也出不来。

而那些在那儿顺利完成一桩探寻的，似乎总能找到自己问题的答案、或难题的解法。它化作一句建议、一条宝贵情报、一件有用的物品，甚至——偶尔——是直接的援手。绯红领地好像总知道小猫们需要什么，而且毫不犹豫地就给它们。

要去那儿，你可以一路沿着海岸线走，但各路通道都被危险的怪兽把守着。也可以走 大浣熊互联网 的隧道网（见第 121 页）。没错，那样又快又省事，但你得跟深处的老鼠们谈妥条件。

据说有些喵师喵法师；喵法师们造了一个咒语，能瞬间把你传送到那儿、或把你带回来。可谁又懂得这样的秘密呢？他们又肯不肯教给几只小猫？

据说绯红领地的“天选者”，有朝一日会找到并用上一个奇怪的通讯盒子。它能召唤一台魔法机器——某种飞碟——在召唤后原地接走他们，把他们送到绯红领地。

#### 搭建绯红领地

每次小猫们带着不同问题去绯红领地，那地方都不会是老样子。所以我们不给你一张固定地图，而是给你一个简单快捷的办法，自己亲手搭出（这一次）小猫们将要闯进去的绯红领地。

这个工具建立在“五室地城”的原则上——那是老式桌上角色扮演游戏的经典套路，用来搭一个晚上就能打完、还带不少反转的短冒险。顾名思义，探索绯红领地要穿过五个彼此相连的地点，最后才抵达探寻的终极目标。

**主题**

先定一个大主题。这个主题围绕一个词展开，作为你描绘绯红领地、里头危险或遭遇的性质等等的一条共同主线。为帮忙，为行掷 1d6、再为列掷 1d6，从下表找一个词（或者干脆自己挑一个）。

| 1d6 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 1 | 电梯 | 颜色 | 易碎 | 激光 | 柔软 | 锈迹 |
| 2 | 机械臂 | 水晶 | 寒冷 | 光 | 阴影 | 扭曲 |
| 3 | 雾 | 瓦砾 | 湿滑 | 音乐 | 波浪 | 漩涡 |
| 4 | 噪音 | 触电 | 吱呀声 | 金属 | 钟摆 | 管道 |
| 5 | 泡泡 | 平衡 | 潮湿 | 镜子 | 植物 | 风 |
| 6 | 热 | 细小 | 闪亮 | 霉 | 恶臭 | 人脸 |

举例：你要是挑了“管道”这个词，就能围绕管道（里里外外）搭一次探索——穿墙而出又穿墙而入的复杂系统，以及你能塞进管道里的一切（奇怪液体、气体、蒸汽、难言之物，等等）。这让整座地城前后连贯，也帮你想出有意思的点子。

**布局**

绯红领地地城的五个房间，不一定要一个接一个排下来。可能的布局五花八门。挑一个，把其余几个围绕它排开。给小猫们留出门路选择，总是有意思的。要生成每个房间，为行掷 1d6、为列掷 1d6，从下表找一段描述（或自己挑）。

> 注意：我们说“房间”，不一定就是个四四方方、又小又封闭的盒子。它更是一个环境——可大可小、或开或合：比如一座路径四通八达的巨大热带温室，或者一座食品加工厂——大房间里摆满罐体、周围连着许多别的地方。它也可以就是一个气闸，所有麻烦都装在它里头。地城的每一块，都是一个换换环境、换换战术、换换难题和解法的机会。

|---|---|---|---|---|---|---|
| 1 | 航天港 | 电梯 | 开阔空间 | 回收仓库 | 种植中心 | 游乐场 |
| 2 | 工坊 | 走廊 | 仓库 | 医院 | 室内公园 | 会议室 |
| 3 | 办公室 | 铸造车间 | 实验室 | 天井 | 温室 | 维护隧道 |
| 4 | 食堂 | 镜厅 | 地下湖 | 地铁站台 | 热电装置 | 弹坑 |
| 5 | 兵营 | 厨房 | 走廊 | 鲸腹之中 | 地铁车厢 | 食品加工厂 |
| 6 | 数据中心 | 旅馆 | 微型工厂 | 粒子加速器 | 圆形观景厅 | 通风井 |

**房间**

地城的每个房间都有不同的机关。它们决定了小猫们将要面对的挑战类型，再结合地城主题，应该能点燃你的想象力。这些机关不必按房间顺序排——其实你想怎么排就怎么排：比如守护者在陷阱之前、镜子之后，然后是抉择，最后才是考验。要给每个考验生成主题，就为它那张表掷 1d6（或自己挑）。

- **考验**：考验要特别动用某一只小猫的能力和勇气。要是他挺不过这一关，他很可能就到不了地城尽头（被打晕、被抬出去、或消失一阵子，等等）。为其主题掷 1d6：1 阻挡；2 挑战；3 技术挑战；4 决斗；5 牺牲；6 变形。
- **抉择**：抉择会一下子牵涉到所有小猫：它们得就某个伦理或道德议题达成一致——牺牲其中一个自己、或牺牲一件喵宝；冒个险去抓住某个机会、或抢点财宝，等等。有些抉择是继续前进的关键；另一些则是次要问题，可能引出可抓可不抓的机会。掷 1d6：1 古怪联盟；2 两害相权；3 机会；4 赌一把；5 密道；6 牺牲。
- **守护者**：守护者通常是一场遭遇——一头或数头生物守着某个地方、不让小猫们继续前进。有的凶暴好斗；有的可以谈条件；有的则像斯芬克斯，爱问谜语和问题。掷 1d6：1 拷问者；2 机器；3 恶徒；4 掠食者；5 难民；6 哨兵。
- **镜子**：镜子这一关，说书人想怎么来就怎么来。如果到目前为止一切都挺顺利（好歹一路摸到了绯红领地），那这儿就该是地狱——难、复杂、过不去。否则，它可以是个港湾、一处喘息落脚、歇歇脚、疗伤的地方（那样的话就跳过下面的掷骰）。掷 1d6：1 刺客；2 灾难；3 对头；4 疾病；5 背叛；6 紧急状况。
- **陷阱**：陷阱可以是个突如其来、立刻让角色陷入危险的事件；也可以是危险的预警，让小猫们动动脑筋、想出避开的办法；或者两者兼有。掷 1d6：1 异常；2 环境险情；3 故障；4 喵法；5 结构问题；6 毒药。

#### 探索绯红领地

探索绯红领地，不该只是一连串检定。每个房间都有它特定的情境、独特的氛围，你得让玩家们用自己的方式去反应。他们多半会冒出一大堆主意和想法，还常常自己抛出些难题、丢给他们的小猫去解。检定应该在那时候才登场——基于他们想出的点子来。

你得在“通往终点所需的推进、保持势头”和“玩家所面对的障碍、挑战、难题的穿插”之间，维持某种平衡——既别手把手帮太多，也别只甩给他们一堆检定骰。小猫们得自己去探索环境，你则边看他们探、边补充细节。你可以让他们找到装备（如果他们记得去找的话），或者想出聪明的解决招。永远要奖励聪明的解法和好点子。

#### 示例

下面是三个绯红领地地城的示例，你可以把前面那些点子打乱重组来用。要是没时间、也没灵感自己编，大可以直接拿去用。

##### 大圆隧道

这座地城的主题是“潮湿”。整座都设在一座巨大粒子加速器的废墟里。入口藏在一个长满植被的地堡里。一扇沉重的金属门打开，通向地上一个又大、又深、又黑的洞。

1. **考验**：隧道壁上固定着一架梯子，还有些机械零件。梯子摇摇晃晃、锈迹斑斑。一次只能一只小猫爬，而且得快——梯子随时可能断。第一只上去的小猫，得敢独自摸黑往下爬。没有绳索够得到底。梯子的踏板又湿又滑。下面深极了。墙上粘着虫子——各种蜗牛、蛞蝓，还有有毒的海葵。小猫须通过一次**强壮**检定：每多 1 个成功（最多 4 个），就抵消 1 点心点损失（无下限）。心点损失来自那些虫子、打滑、木刺等等。隧道最底下有一台机器，驱动着一部电梯。到了那儿的小猫须通过一次**聪明**检定（简单）才能启动它、把电梯送到顶上给大家用。检定失败，意味着电梯能运转，但会电到启动它的小猫一下——底下到处都是水——他再失去 1 心点。
2. **镜子**：如果一路都格外难，小猫们会撞见一间小小的、四壁潮湿的冷屋子。角落里一台老旧的零食饮料机居然还开着、还能用，里头塞满能吃的东西（保质期早就过了，但那无所谓）。如果一路都很轻松，小猫们则会发现自己站在一条长长的、被水淹没的走廊尽头。它们得一头扎进浓稠黑水里，有怪东西蹭过它们的毛、钻进钻出它们的包。它们得当心别冻僵、别在半路上弄丢装备。
3. **抉择**：小猫们来到一条又大又圆的隧道，左右两边都能走。面前是一台看着极其复杂的机器，面板上满是开关、VU 表和指示灯。有的在昏暗地闪。上方有个巨大金属柜，上面一根大拉杆扳在高位。到底碰不碰？拉动拉杆会发生一串事（灯光四处闪烁、机器苏醒、机械臂动起来、电火花四溅、潮气引起各种怪声，隧道里的住民也停止爬动、躲了起来）；不拉又是另一番景象（长廊依然又黑又潮，住在里头的爬虫可能会扑上来、或挡小猫的道）。两种选择都风险不小。而那个根本问题依然悬着：要是不开机器，绯红领地理会小猫们的问题吗？
4. **守护者**：一个**大光腚**住在圆走廊的右侧，靠吃蜗牛和海葵为生。他穿一件大致是白色的长衬衫。他正用发光粉笔在墙上写复杂的数学公式。小猫们一露面，他就开始考它们数学：先是加减乘除的简单运算，再问更逻辑的问题：“要切多少刀，才能把一块巧克力掰成一格一格？”小猫们要是不想让他跟着自己一路走隧道、没完没了地问些让人发懵的问题，就得把他的问题全答上来。
5. **陷阱**：圆走廊左侧，小猫们看见一个大红按钮，还有一个倒计时器，跳出随机、不祥的数字。红按钮能停下倒计时吗？能重置吗？其实都无所谓：你只是想引起小猫们的注意而已。再往前一点，墙上有道裂缝，一股水流正朝机器蔓延，引起短路。一切开始嗡嗡作响、滋滋冒烟——当心：粒子束来了！快躲开！最后，小猫们问题的答案，多半会和粒子对撞的结果一起，显示在一块屏幕上。

##### 希尔伯特旅馆

这座地城的主题是“易碎”，一切发生在一座巨大的旅馆建筑群里。入口埋在灌木丛中：一扇磨砂玻璃大门，上面用大大的黑字写着“希尔伯特旅馆”希尔伯特旅馆。小猫们一进旅馆，很快就会发现：里头看着比外头大得多，仿佛没有尽头。然而一切——家具、墙面地面的覆层、织物——都娇弱易碎得惊人，随时会破、会裂。轻轻一动就可能弄坏东西。

1. **镜子**：如果一路都很顺，迎接小猫们的会是几台又大又亮、擦得锃亮的黑色机器人。它们不太客气，命令小猫们立刻离开（脱鞋！）。打**呲牙战**它们挺强，可一旦小猫们动真格，它们立刻散架。如果一路都很艰难，迎接小猫的则是一群沉默却殷勤的白色烤漆机器人：它们拿走行李，把小猫们护送到一间餐厅吃饭。它们把包一溜烟送进各种难找的房间，总而言之，把小猫们伺候得无微不至、无微不至到它们头晕！不过小心：它们也脆得很，一上手帮忙就容易散架，更添混乱。
2. **守护者**：一个又大又圆的灰色机器人，身上画着一把金钥匙，用一种谁也听不懂的语言欢迎小猫们，开始盘问它们、递上奇怪的表格要填、还要它们拿东西来换（却不说清到底要换什么）。要是小猫们不配合，它可能动武；可一旦被狠狠揍上一下，它们会发现它其实也不怎么结实。不过别的黑色机器人会赶来帮它。
3. **考验**：**聪明**属性最高的那只小猫（或最好奇的那只），盯上了几台赌博机。它觉得，像自己这么聪明的，肯定能赢不少。可一玩起来就着了迷，怎么也挪不开步。这只小猫在一间偌大的赌场里迷了路，从一台机器晃到另一台，有输有赢，渐渐消失在迷宫深处。
4. **抉择**：电梯还是楼梯？选电梯，会发生两件事：不管按哪个钮，它都绝不会真把你送到想去的地方。然后电梯就坏了——在一个万物皆脆的地方，这再正常不过。可一旦卡在两层楼之间，小猫们怎么出去？选楼梯，小猫们就得找对楼梯、爬一层又一层，累得半死。这楼比猫树城还高！而且到处都是黑机器人和白机器人，存心给它们添堵。
5. **陷阱**：整个地板都是玻璃做的。当然，脆得不能再脆。那么，当地板眼看就要裂开、碎掉时，你要怎么才能走到旅馆唯一的客人面前——那位正坐在大床上的客人？也许正是这位迷了路、孤零零、慌了神的客人，身上揣着小猫们要找的钥匙。他被困在那儿，下不了床（地板太脆，他一踩就碎），由一长串过于殷勤的机器人伺候着。小猫们能把这位客人安全弄出去吗？

##### 中央公园

这座地城的主题是“噪音”，发生在一座杂草丛生的城市公园里。里头有攀岩墙、滑板场、小小的景观桥、花花绿绿的混凝土恐龙雕像、游乐设施、滑梯、跑步机、小木屋，等等。一切都半毁着：油漆剥落、混凝土崩裂、金属生锈、木头腐烂，还长满了草、荆棘和荨麻。怪就怪在：一座老式大都市的所有声响都听得见（汽车喇叭、凄厉警笛、火车、飞机），却看不见任何声源。而且到处都是风铃和风鸣琴。入口是一扇生锈的铁门，上面挂着奇怪的牌子（野狗帮显然是不准在公园里尿尿的院狗）。

1. **陷阱**：一进公园，一阵攻击性的噪音浪潮就劈头盖脸砸向小猫。它们不习惯，弄不清这些声音是什么、从哪来。要是不赶紧想办法降噪，它们就会晕头转向、被吵得神志恍惚。一个解决思路，或许是去敲那些风铃——它们柔和的音符似乎能压低城市噪音的音量。不管用什么招，它们都得动这个脑筋（而且整个冒险里都得重复这个法子）。
2. **抉择**：当小猫们不得不踏上一片既无树、也无风铃的大空地时，它们得选：是捂住耳朵（那彼此就没法交流了），还是硬着头皮穿过那令人天旋地转的噪音？而当然，一走到空地中央，巨型草莓就从地里蹦出来攻击小猫们（管他呢？这儿可是绯红领地！）。
3. **考验**：能看见一座巨大的钟楼，坐落在一座高崖顶端。小猫们很快意识到，它可以用来给整座公园消一会儿音。得有一只小猫爬上去。攀爬有哪些危险？爬到塔上又如何——门上写着，一次只准进一只小猫？
4. **守护者**：公园管理员是一只巨大的狼狗，毛黑得像夜，嘴角耷拉着，从小猫们一进公园就开始追踪它们。他疯了（而且彻底聋了），因为太久太久被城市的噪音折磨。他的目标是把小猫们逼回大门。他一路骚扰、追猎，出手就立刻消失，吓人极了。
5. **镜子**：如果小猫们一路打得很辛苦，它们会来到一片安静祥和的湖畔，噪音在这里被柔化了。管理员不敢靠近这儿。它们可以歇歇脚、扎个营。如果小猫们一路都很轻松，湖岸的噪音反而越来越大，它们耳朵生疼，还听见各种怪事——它们能听见沃尔特辱骂它们、叫它们给他把财宝带回来！

小猫们要找的答案或解法，会写在一块块巨大的横匾上，装饰着一座俯瞰公园的大房子——观景楼。之后，它们只需找到出口即可。
