<h1 id="毁灭之塔the-tower-of-ruin">毁灭之塔（The Tower of Ruin）</h1>
<p><strong>一个《塔罗织者》（Tarot Weaver）冒险剧本</strong></p>
<p>在彩虹谷（Prismatic Vale）的深处，据说耸立着一座古老的魔塔，在那里，生者与死者世界之间的界限已彻底融化。许多人寻觅至此，试图复活他们挚爱的亲人，或是战胜死亡本身。然而，鲜有人知晓这座魔塔背后可怕的真相。</p>
<p>梅芙女王（Queen Maeve）委托织者们寻找这座魔塔，并复活她已故的妻子阿斯特里亚女王（Queen Astrea）。必须有一位角色在其物品栏中携带<strong>阿斯特里亚的项链（Astrea's Necklace）</strong>。</p>
<p>寻找魔塔远比想象中困难，因为它在同一个地点停留的时间绝不会超过几天。织者们必须做好相应的规划。</p>
<hr>
<h2 id="究竟发生了什么what-is-really-happening">究竟发生了什么？（WHAT IS REALLY HAPPENING?）</h2>
<p>这座魔塔是早已作古的死灵法师伊努佐尔（Inuzor）的杰作，他曾企图打开通往苍白之地（The Pale，即亡者之地）的门户。然而，随后引发的魔法灾难不仅当场夺走了伊努佐尔的生命，还在两个世界之间撕开了一条不稳定的裂隙。如今，魔塔在数个不同的时空节点之间来回振荡震荡。</p>
<p>虽然魔塔能够召唤亡灵的灵魂，但这些灵魂无法离开魔塔的领地，被永恒地困在其中，无法转世。魔塔范围之内同时只能困住<strong>七个</strong>灵魂。</p>
<p>如果伊努佐尔在魔塔领地内已有七个灵魂被困的情况下重返魔塔，他将完成仪式，将魔塔永久转化为通往苍白之地的门户，从而对生者的世界造成毁灭性的灾难。</p>

<h2 id="寻找魔塔finding-the-tower">寻找魔塔（FINDING THE TOWER）</h2>
<p>[ S ] ---&gt; (1) [ 宝剑 ]
(2) [ 权杖 ]
(3) [ 圣杯 ]
(4) [ 星币 ]</p>
<p><img src="/imgs/2026-10-21/caxg7FIkMyt5PGk1.png" alt="输入图片说明">  </p>
<p>织者们从 <strong>“S”</strong> 点出发。只有当移动到对应空间时，卡牌 1、2、3 和 4 才会翻开。所有其他卡牌可保持朝下，代表茂密而多山的高原森林。每张卡牌代表 1 天的旅程尺度。如果织者消耗其回合进行搜寻或侦察，可以从任何相邻的卡牌位置观测到魔塔。</p>
<p>甲谕官（Oracle）从命运之牌（Fate Deck）中抽取一张卡牌，以确定魔塔当前出现的位置：</p>
<ul>
<li><strong>宝剑（Swords）</strong>：位置 1</li>
<li><strong>权杖（Wands）</strong>：位置 2</li>
<li><strong>圣杯（Cups）</strong>：位置 3</li>
<li><strong>星币（Pentacles）</strong>：位置 4</li>
<li><strong>大阿卡纳（Maj. Arcana）</strong>：位置无变化</li>
<li><strong>愚者（The Fool）</strong>：魔塔消失。将卡牌洗回牌堆重洗。</li>
</ul>
<blockquote>
<p><em>注：如果连续抽到相同花色，魔塔将停留在原位（例如连续抽到 3 张宝剑牌，意味着魔塔在位置 1 停留 3 天）。</em></p>
</blockquote>
<p>魔塔本身是对大自然的一种亵渎。野生动物会本能地避开魔塔的方向。如果在魔塔附近触发强盗遭遇，织者们遇到的将改为<strong>阿尔伯特（Albert）</strong>。</p>

<h3 id="地点检索locations">地点检索（LOCATIONS）</h3>
<h4 id="1-灼烧陨石坑blistering-crater">(1) 灼烧陨石坑（Blistering Crater）</h4>
<ul>
<li><strong>对应卡牌</strong>：太阳（The Sun，逆位 R）</li>
<li><strong>描述</strong>：毫无生机。在此处进行的**身手（Prowess）**检定处于劣势（Disadvantage）。</li>
<li>内部散落着锯齿状的黑色岩石，散发着奇异的能量。如果将其打造为武器，对不死生物可造成额外的伤害（伤害 +2）。</li>
<li><strong>危险</strong>：在此过夜会引发极其逼真的噩梦。次日进行的所有检定均处于劣势。</li>
</ul>
<h4 id="2-月光湖moonlit-lake">(2) 月光湖（Moonlit Lake）</h4>
<ul>
<li><strong>对应卡牌</strong>：月亮（The Moon，正位 U）</li>
<li><strong>描述</strong>：深邃树林中闪烁着微光的湖泊。饮用湖水可恢复所有生命值（Hit Points）。</li>
<li>动物们会平和地来到水边饮水。如果对这里的野生动物施加暴力，湖水将变得黑化腐败，持续 X 天。饮用黑化湖水将受到 X 点宝剑（Swords）伤害。</li>
<li><strong>特性</strong>：宁静的水源吸引着来自四面八方的生物。遭遇概率翻倍，但野生动物不会主动发起攻击。</li>
</ul>
<h4 id="3-石质祭坛stone-altar">(3) 石质祭坛（Stone Altar）</h4>
<ul>
<li><strong>对应卡牌</strong>：死神（Death，逆位 R）</li>
<li><strong>描述</strong>：一个直径约 60 英尺的大型石质台座，周围环绕着七根石柱。符文在火光中闪烁着微光。</li>
<li>中间的讲台上摆放着一本奇异的典籍——<strong>伊努佐尔的死灵术魔导书（Inuzor's Tome of Necromantic Magics）</strong>[cite: 55, 56]。可用此书将伊努佐尔从苍白之地召唤出来[cite: 55, 56]。</li>
<li>远处偶尔会传来阵阵诡异的嚎叫声。</li>
</ul>
<h4 id="4-荒废王座idle-throne">(4) 荒废王座（Idle Throne）</h4>
<ul>
<li><strong>对应卡牌</strong>：皇帝（The Emperor，逆位 R）</li>
<li><strong>描述</strong>：完全由荆棘和树木交织生长而成的王座。</li>
<li><strong>遭遇</strong>：有 1/4 的概率遇到<strong>森林之主（Lord of the Wood）</strong>。祂可能会援助织者，也可能会带来敌意。</li>
<li>松鼠们会将珠宝和小饰品收集到王座前的一个黄铜碗里。偷窃这些物品会激怒森林之主，导致祂在接下来的每一次随机遭遇中都会现身。</li>
</ul>
<blockquote>
<p><strong>森林之主（Lord of the Wood）</strong> —— 妖精领主（Fey Lord）</p>
<ul>
<li><strong>属性</strong>：HP 12 | AR 3 | S 12 W 10 C 10 P 12</li>
<li><strong>能力</strong>：能够施放所有派系的魔法。拥有坚硬的皮毛/树皮（AR 3）。祂极度憎恨魔塔，但拒绝踏入魔塔领地半步。</li>
<li><strong>弱点</strong>：铁制武器对其可造成双倍伤害。若被杀死，将在 3 天后复活。但如果在魔塔领地内将其杀死，祂将彻底永久死亡。</li>
</ul>
</blockquote>

<h2 id="伊努佐尔之塔inuzors-tower">伊努佐尔之塔（Inuzor's Tower）</h2>

<h3 id="魔塔区域详解tower-locations">魔塔区域详解（TOWER LOCATIONS）</h3>
<h4 id="1-中庭courtyard">(1) 中庭（COURTYARD）</h4>
<ul>
<li><strong>对应卡牌</strong>：世界（The World，逆位 R）</li>
<li>敞开的吊闸门通往一座华丽的中庭。庭院中央立着一座精致的喷泉，雕刻着一名穿长袍的人物用箭矢刺穿骷髅胸膛的画面。水流从骷髅的伤口中源源不断地涌出。</li>
<li>铭牌上刻着一行字：“<strong>以此，我将征服死亡本身。</strong>”</li>
</ul>
<h4 id="2-仆从之所servants-house">(2) 仆从之所（SERVANTS HOUSE）</h4>
<ul>
<li><strong>对应卡牌</strong>：女祭司（The High Priestess，逆位 R）</li>
<li>一处朴素的居所，整体设计考虑到了集体生活的需求。炉火正加热着一锅永不干涸的炖菜（Perpetual Stew），其中一张床铺整洁地铺着。显然最近一直有人在此居住。</li>
</ul>
<h4 id="3-魔塔入口tower-entry">(3) 魔塔入口（TOWER ENTRY）</h4>
<ul>
<li><strong>对应卡牌</strong>：节制（Temperance，逆位 R）</li>
<li>魔塔的大堂底层。摆放着许多奇异的炼金器材与试剂，大部分处于混乱损坏的状态。</li>
<li><strong>通道</strong>：楼梯通往区域 <strong>(6)</strong>。如果在内部关上大门并敲门 7 次，将直接通往区域 <strong>(5)</strong>。</li>
</ul>
<h4 id="4-花园garden">(4) 花园（GARDEN）</h4>
<ul>
<li><strong>对应卡牌</strong>：皇后（The Empress，正位 U）</li>
<li>一座杂草丛生、生长着各种异域植物的花园。树上结满了异界的果实，食用后可能会治愈伤势，也可能会造成伤害。</li>
</ul>
<h4 id="5-星空阶梯astral-stairway">(5) 星空阶梯（ASTRAL STAIRWAY）</h4>
<ul>
<li><strong>对应卡牌</strong>：星星（The Star，正位 U）</li>
<li>一条穿过星光熠熠的虚空、不断向上盘旋的螺旋楼梯，直接通往区域 <strong>(8)</strong>。</li>
</ul>
<h4 id="6-实验室laboratory">(6) 实验室（LABORATORY）</h4>
<ul>
<li><strong>对应卡牌</strong>：魔术师（The Magician，正位 U）</li>
<li>这里记录着伊努佐尔黑暗研究的成果。大量的玻璃器皿、不知名的机械和干枯的尸体散落了一地。</li>
<li><strong>通道</strong>：楼梯向上通往 <strong>(7)</strong>，向下通往 <strong>(3)</strong>。</li>
</ul>
<h4 id="7-仪式室ritual-room">(7) 仪式室（RITUAL ROOM）</h4>
<ul>
<li><strong>对应卡牌</strong>：恶魔（The Devil，逆位 R）</li>
<li>房间里布满了魔法符文。七座底座环绕着一条微小的空间裂隙，七条白色的虚无丝线从中延伸出来，连接着被困在魔塔领地内的灵魂。</li>
<li><strong>解封机制</strong>：每个底座上都摆放着一件与被困灵魂密切相关的个人物品。必须破坏底座上的物品，并替换为另一个人的随身物品，才能释放原本的灵魂并绑定新的灵魂。</li>
<li><strong>伊努佐尔的灵魂</strong>在传送门另一侧急切地等待着，会向任何经过的人寻求帮助，请求他们帮自己找到<strong>魔导书（Tome）</strong>。如果遭到追问，他会撒谎说自己只是想解除这个邪恶的诅咒。</li>
</ul>
<h4 id="8-引擎室the-engine">(8) 引擎室（THE ENGINE）</h4>
<ul>
<li><strong>对应卡牌</strong>：审判（Judgement，逆位 R）</li>
<li>一台发出生机勃勃轰鸣声的庞大黄铜机械巨兽占据了整个空间。</li>
<li><strong>破坏后果</strong>：蓄意破坏这台引擎将彻底摧毁魔塔，释放所有被困的灵魂，并永久关闭通往苍白之地的传送门。</li>
</ul>
